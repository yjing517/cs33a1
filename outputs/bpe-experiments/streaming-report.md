# TinyStories 流式读取实验

按完整文档流式预分词，并按预分词字符串累计词频。UTF-8 由文本流解码；保留足以识别跨块特殊 token 的文本。无特殊 token 或空特殊 token 时，沿用整段语义。合并堆保持原实现。

| 输入 | 训练时间（秒） | 峰值 RSS（KiB） |
|---|---:|---:|
| 200 MiB，前版 | 27.578 | 1,063,768 |
| 200 MiB，流式 | 23.115 | 128,692 |
| 600 MiB，流式 | 65.890 | 143,808 |

200 MiB 两次的 vocab 和有序 merges 重载后逐项一致。跨块检查覆盖重叠分隔符、连续分隔符、Unicode、换行及空输入，并用 1–23 字符块与原分割逻辑对照。官方 BPE 测试 3/3 通过。600 MiB 样本从已校验的官方训练集前缀截到文档分隔符，实际 629,144,830 字节。

200 MiB RSS 降幅 87.9%。600 MiB 继续增长的内存来自保留的词频与合并状态等，尚未单独量化堆和 pair 索引。进程地址空间上限 2.5 GiB，样本超时 300 秒。

## 完整 TinyStories

已校验的官方训练文件为 2,227,753,162 字节。完整训练用时 250.947 秒，峰值 RSS 163,620 KiB，退出码 0。限制为 1,800 秒和 2.5 GiB 进程地址空间。训练入口保存后成功重载校验 10,000 个词表项、9,743 次合并和唯一的特殊 token。三个 15 字节最长项为带前导空格的 accomplishment、disappointment、responsibility。

完整产物见 stream-full-tinystories/bpe.pkl，原始输出见 stream-full-tinystories.log。OpenWebText 至此只验证了 32K 样本。
